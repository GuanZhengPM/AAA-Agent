Run an arbitrary command in the selected workspace using `cmd.exe` on Windows and the configured POSIX shell on macOS/Linux. Returns combined stdout/stderr and exit code. Every invocation requires host approval because arbitrary shell can read files outside the workspace; sandboxing limits network and writes where supported but is not a confidentiality boundary. You MUST match command syntax to the reported platform. Use for builds, tests, and smoke checks. NEVER run destructive commands unless the user requested them.
